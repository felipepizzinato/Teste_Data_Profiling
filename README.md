# Teste FG Data Profiling

Este repositório foi criado para testar a biblioteca **FG Data Profiling**, utilizada para automatizar e agilizar a Análise Exploratória de Dados (EDA) com Python.

O objetivo é explorar a geração automática de relatórios, estatísticas e visualizações para facilitar a compreensão inicial de bases de dados.

**Tecnologias utilizadas:**
- Python
- Pandas
- FG Data Profiling
- Jupyter Notebook

> Projeto desenvolvido apenas para fins de estudo e experimentação.
